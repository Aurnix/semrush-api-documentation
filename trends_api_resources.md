## Columns Reference

All `export_columns` parameter values across Trends API methods.

> Column names cannot be changed. Column order and count can be customized. Semrush will notify users before removing any columns.

| Column | Description | Used In |
|--------|-------------|---------|
| `accuracy` | Data accuracy score: `1`, `2`, or `3` (3 = highest) | Data Accuracy, Traffic Summary |
| `age` | Age group (e.g. `18-24`, `25-34`) | Age and Sex Distribution |
| `age_18_24` … `age_65_plus` | Users by age band | Industry Categories |
| `ai_assistants` | Traffic from AI assistant platforms (e.g. ChatGPT) | Daily Traffic, Subfolders, Top Pages, Traffic Summary, Weekly Traffic |
| `ai_assistants_traffic` | Same as above (Industry Categories column name) | Industry Categories |
| `ai_search` | Traffic from AI-powered search engines | Daily Traffic, Subfolders, Top Pages, Traffic Summary, Weekly Traffic |
| `ai_search_traffic` | Same as above (Industry Categories column name) | Industry Categories |
| `avg_visit_duration` | Average time spent on an analyzed page | Top Pages |
| `bounce_rate` | Share of single-page sessions | Daily Traffic, Industry Categories, Subfolders, Traffic Rank, Traffic Summary, Weekly Traffic |
| `bounced_visits` | Count of single-page sessions | Industry Categories |
| `categories` | Industry categories for a site (semicolon-separated if multiple) | Audience Insights, Geo Distribution, Traffic Destinations, Traffic Sources, Traffic Summary |
| `category` | Single industry category | Audience Interests |
| `channel` | Traffic channel: `direct`, `referral`, `search`, `social`, `mail`, `display_ad`, `ai_assistants`, `ai_search` | Traffic Sources |
| `conversion` | Share of sessions ending in a purchase | Purchase Conversion |
| `conversion_rate` | Estimated share of sessions ending in checkout | Industry Categories |
| `country` | ISO 3166-1 Alpha-2 country code | Most methods |
| `country_code` | Same as above (Industry Categories column name) | Industry Categories |
| `desktop_share` | Share of desktop traffic | Daily Traffic, Geo Distribution, Subdomains, Top Pages, Traffic Rank, Traffic Summary, Weekly Traffic |
| `device_type` | Device: `desktop` or `mobile` | Most methods |
| `direct` | Direct traffic | Daily Traffic, Subfolders, Top Pages, Traffic Summary, Weekly Traffic |
| `direct_traffic` | Same as above (Industry Categories column name) | Industry Categories |
| `display_ad` | Display/banner advertising traffic | Daily Traffic, Subfolders, Top Pages, Traffic Summary, Weekly Traffic |
| `display_ad_traffic` | Same as above (Industry Categories column name) | Industry Categories |
| `display_date` | Date of the data | Most methods |
| `domain` | The domain analyzed | Subdomains, Traffic Rank |
| `domain_name` | Same as above (Industry Categories column name) | Industry Categories |
| `edu_level_*` | Education level breakdowns | Industry Categories |
| `email_traffic` | Email campaign traffic | Industry Categories |
| `entrance_traffic` | Sessions that entered the site via this page | Top Pages |
| `entrances` | Sessions that entered via this subfolder | Subfolders |
| `exits` | Sessions that exited from this page/subfolder | Subfolders, Top Pages |
| `facebook_traffic` | Traffic from Facebook | Industry Categories |
| `female` / `male` | Share of female/male visitors | Industry Categories |
| `female_share` / `male_share` | Female/male share of total audience | Age and Sex Distribution |
| `female_users` / `male_users` | Count of female/male visitors | Age and Sex Distribution |
| `female_18_24` … `female_65_plus` | Female visitors by age band | Industry Categories |
| `male_18_24` … `male_65_plus` | Male visitors by age band | Industry Categories |
| `from_target` | Domain users came from | Traffic Sources |
| `high_income` / `middle_income` / `low_income` | Income level breakdown | Industry Categories |
| `hits` | Total pageviews | Daily Traffic, Industry Categories, Weekly Traffic |
| `household_size_1` … `household_size_10plus` | Visitors by household size | Industry Categories |
| `income_type` | Income level: `high`, `middle`, or `low` | Income Distribution |
| `instagram_traffic` | Traffic from Instagram | Industry Categories |
| `is_adult` | Whether domain has adult content: `true`/`false` | Audience Insights |
| `is_forecasted` | Whether the row is forecasted data: `true`/`false` | Daily Traffic, Weekly Traffic |
| `linkedin_traffic` | Traffic from LinkedIn | Industry Categories |
| `mail` | Email traffic | Daily Traffic, Subfolders, Top Pages, Traffic Summary, Weekly Traffic |
| `mobile_bounce_rate` | Bounce rate for mobile users | Traffic Summary |
| `mobile_hits` | Pageviews from mobile | Traffic Summary |
| `mobile_pages_per_visit` | Pages per session on mobile | Traffic Summary |
| `mobile_share` | Share of mobile traffic | Daily Traffic, Subdomains, Top Pages, Traffic Rank, Traffic Summary, Weekly Traffic |
| `mobile_users` | Unique mobile visitors | Subdomains, Traffic Summary |
| `mobile_visits` | Total mobile sessions | Subdomains, Traffic Rank, Traffic Summary |
| `occupation` | Occupation category | Occupation Distribution |
| `occupation_fulltimework` … `occupation_unemployed` | Occupation breakdown columns | Industry Categories |
| `overlap_score` | Audience overlap level between domains | Audience Insights |
| `overlap_users` | Unique visitors shared between analyzed and listed domains | Audience Insights |
| `page` | Specific page URL | Top Pages |
| `pages_per_visit` | Pages viewed per session | Daily Traffic, Subfolders, Traffic Rank, Traffic Summary, Weekly Traffic |
| `paid` ⚠️ | Deprecated: all paid traffic | Subfolders, Top Pages, Traffic Summary |
| `pinterest_traffic` | Traffic from Pinterest | Industry Categories |
| `prev_traffic` | Prior month's traffic for comparison | Geo Distribution, Traffic Destinations, Traffic Sources |
| `rank` | Traffic rank (1 = highest traffic) | Daily Traffic, Traffic Rank, Traffic Summary, Weekly Traffic |
| `reddit_traffic` | Traffic from Reddit | Industry Categories |
| `referral` | Referral traffic | Daily Traffic, Subfolders, Top Pages, Traffic Summary, Weekly Traffic |
| `referral_traffic` | Same as above (Industry Categories column name) | Industry Categories |
| `report_date` | Report date | Industry Categories |
| `search` ⚠️ | Deprecated: total search traffic | Subfolders, Top Pages, Traffic Summary |
| `search_organic` | Organic search traffic | Daily Traffic, Subfolders, Top Pages, Traffic Summary, Weekly Traffic |
| `search_organic_traffic` | Same as above (Industry Categories column name) | Industry Categories |
| `search_paid` | Paid search traffic | Daily Traffic, Subfolders, Top Pages, Traffic Summary, Weekly Traffic |
| `search_paid_traffic` | Same as above (Industry Categories column name) | Industry Categories |
| `similarity_score` | Audience similarity between domains | Audience Insights |
| `size` | Household size (`1`–`10+`) | Household Distribution |
| `social` ⚠️ | Deprecated: all social traffic | Subfolders, Top Pages, Traffic Summary |
| `social_domain` | Social platform domain (e.g. `facebook.com`) | Social Media |
| `social_name` | Social platform name (e.g. `Facebook`) | Social Media |
| `social_organic` | Organic social traffic | Daily Traffic, Subfolders, Top Pages, Traffic Summary, Weekly Traffic |
| `social_organic_traffic` | Same as above (Industry Categories column name) | Industry Categories |
| `social_paid` | Paid social traffic | Daily Traffic, Subfolders, Top Pages, Traffic Summary, Weekly Traffic |
| `social_paid_traffic` | Same as above (Industry Categories column name) | Industry Categories |
| `subdomain` | Subdomain (e.g. `blog.example.com`) | Subdomains, Subfolders |
| `subfolder` | Subfolder path (e.g. `/products/shoes`) | Subfolders |
| `sum_time_on_site` | Total time spent on site | Industry Categories |
| `target` | The domain being analyzed | Most methods |
| `target_type` | Target type: `domain` or `subdomain` | Subdomains |
| `target_users` | Total users for the target domain | Audience Insights |
| `time_on_site` | Average session duration | Daily Traffic, Traffic Rank, Traffic Summary, Weekly Traffic |
| `time_on_subfolder` | Average time in a subfolder | Subfolders |
| `to_target` | Destination domain users visited after the target | Traffic Destinations |
| `total_traffic` | Combined traffic from all sources | Industry Categories |
| `total_users` | Combined unique user count | Subdomains |
| `total_visits` | Total visit count | Subdomains |
| `traffic` | Total traffic volume | Geo Distribution, Top Pages, Traffic Destinations, Traffic Sources |
| `traffic_diff` | Change in traffic vs. prior period | Traffic Sources |
| `traffic_share` | Share of total traffic | Geo Distribution, Subdomains, Subfolders, Top Pages, Traffic Destinations, Traffic Sources |
| `traffic_type` | `organic` or `paid` | Traffic Sources |
| `twitter_traffic` | Traffic from Twitter/X | Industry Categories |
| `unique_pageviews` | Distinct pageviews by unique users | Subfolders |
| `unique_visitors` | Distinct users | Industry Categories |
| `unknown_channel` | Traffic with undetermined source | Traffic Summary |
| `users` | Total unique visitors | Most methods |
| `users_by_target` | Users associated with a specific target | Top Pages |
| `users_captured` | Users tracked via login, cookies, or CRM | Industry Categories |
| `users_score` | Affinity score for targeting or analysis | Audience Interests, Social Media |
| `users_share` | Share of audience in a demographic group | Education, Household, Income, Occupation Distribution |
| `vk_traffic` | Traffic from VK | Industry Categories |
| `youtube_traffic` | Traffic from YouTube | Industry Categories |
